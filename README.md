## 📦 Core Components
- **OS:** Arch Linux
- **Window Manager:** Hyprland
- **Terminal:** Kitty
- **Bar:** Waybar
- **Launcher:** Wofi
- **File Manager:** Yazi
- **Notifications:** Mako
- **Wallpaper Daemon:** awww

## 🚀 Installation
**Warning:** This script will update your system and overwrite existing configs in `~/.config/` for the apps listed above. 

Clone this repository and run the install script:
```bash
git clone [https://github.com/YourUsername/your-repo-name.git](https://github.com/YourUsername/your-repo-name.git) ~/my-rice
cd ~/my-rice
