# Chad's Arch & Hyprland Rice

A custom automated Wayland setup for Arch Linux, featuring dynamic tiling, custom keybinds, and an automated deployment script.

## 📦 Core Components
- **OS:** Arch Linux
- **Window Manager:** Hyprland
- **Terminal:** Kitty
- **Bar:** Waybar
- **Launcher:** Wofi
- **File Manager:** Yazi
- **Notifications:** Mako
- **Wallpaper Daemon:** awww
